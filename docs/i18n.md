# Internationalization

## Locales

| Code | Language | Messages |
|------|----------|----------|
| `es` | Español (default, source of truth) | `messages/es.json` |
| `ca` | Català | `messages/ca.json` |
| `eu` | Euskara | `messages/eu.json` |
| `gl` | Galego | `messages/gl.json` |
| `en` | English | `messages/en.json` |

- Enabled in [`src/i18n/routing.ts`](../src/i18n/routing.ts) (`routing.locales`) and in the matcher of [`src/middleware.ts`](../src/middleware.ts). Galician is `gl` (ISO 639-1; `ga` is Irish).
- Every url has the locale prefix (`/ca/parliament`). The middleware redirects `/` using the browser's `Accept-Language`, falling back to `es`.
- The names shown in the switcher are in [`src/locale.ts`](../src/locale.ts) (`codeToLanguage`), each written in its own language.

## Language switcher

`LanguageSwitcher` (in the navbar, under the legislatura switcher) shows the current code and lists every locale. Choosing one opens the same page in that language with `router.replace(pathname, { locale })` from `next-intl/navigation`, keeping the query string.

## Adding or changing texts

1. Add the key to `messages/es.json` first: Spanish is the reference.
2. Add the same key, with the same placeholders (`{count}`, `{roman}`, plural branches and `#`), to **every** other file.
3. `npm run test` fails if a file has a missing or extra key, a changed placeholder or an empty text (`src/__tests__/i18n/messages.test.ts`).

## Usage

```typescript
import { useLocale, useTranslations } from "next-intl";
const t = useTranslations("namespace");
const locale = useLocale();
formatDate(vote.date, locale); // dates in the reader's language
```

## Not translated

Content that comes from the database or from Gemini stays in Spanish: promises, AI analyses, vote titles and the "En pocas palabras" summaries. `PlainSummary` falls back to the Spanish summary when there is none for the locale (`SUMMARY_LOCALES` in `lib/services/ai/proposalSummaryAI.ts` is still `['es']`).
